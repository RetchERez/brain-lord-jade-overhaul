# Reporting a problem

Use [the bug report form](https://github.com/RetchERez/brain-lord-jade-overhaul/issues/new/choose) and include:

- The patch version and emulator/core version
- Whether you started a new game and used a clean headerless USA ROM
- The area, equipped fairies, their levels and the steps that reproduce the issue
- What you expected and what actually happened
- A screenshot or short clip if it helps

Do not attach game ROMs. If a save is needed, a maintainer can request the
specific checkpoint details. Start with the installation and compatibility
information in [readme.txt](readme.txt).
