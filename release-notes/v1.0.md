# Brain Lord: Jade Overhaul v1.0

Keep all 13 original individual fairies and discover Rapid, Ward, Frost and
Poison for 17 total, with the original two-fairy limit.

## Player download

Download **brain_lord_jade_overhaul_v10.zip** below. It contains only the BPS patch and readme,
including all 17 Jade locations. Version 1.0 uses `v10` in the filename.
The separate **brain_lord_jade_overhaul_v10_screenshots.zip** contains nine unscaled 256×224 PNG screenshots.

## Highlights

- All 13 original individual fairies preserved, including their original counterparts
- Rapid, Ward, Frost and Poison added as four optional dungeon discoveries
- Original shops, Jade sources, prices, sphere drops and story gates retained
- 50 EXP for each equipped eligible fairy from each collected sphere
- Distinct new fairy sprites, projectiles and inventory Jade icons
- Specific Jade names before the naming keyboard
- Native Poison damage flashes and hit sounds, without added stun or knockback
- Original two-fairy limit and ROM size retained

Poison's nonlethal ticks now use the game's normal damage blink or flash and
enemy hit sound. Rapid and Frost's native hit feedback is verified; Ward keeps
its native deflection feedback. Boss immunity and native lethal handling remain.

## Apply to

- Clean headerless Brain Lord USA ROM
- Original size: 1,572,864 bytes
- Original CRC32: AC443D87
- Original SHA-256: f4666355e7fea434843dc6d5119673bd6c23e69b884aac0b382ff036997e52b5

Apply the BPS once to the clean ROM and start a new game for all four treasures.
Keep saves from earlier 12-fairy builds and emulator states separate. No ROM is included.

## Verification

26 native groups, 66 unit tests and 9 mathematical regressions passed. All 136
pairs were compared mathematically and 272 native slot orders exercised.
Both independent patch applications reproduced the target without ROM expansion.
No full campaign playthrough or real-console certification was performed.
